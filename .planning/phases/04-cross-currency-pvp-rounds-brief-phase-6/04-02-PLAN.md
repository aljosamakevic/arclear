## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| anyone → executePvP | Fully permissionless; all calldata untrusted (legs, digests, rate, signatures) |
| router → hubs | Router forwards untrusted legs; hubs independently re-validate everything (unanimity, nonce, collateral) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-05 | Spoofing | hub binding | mitigate | constructor immutables — no calldata hub addresses ever (evil-hub substitution structurally closed, RESEARCH Q3) |
| T-04-06 | Tampering | calldata legs vs signed legs | mitigate | on-chain digest recomputation via each hub's hashRound + LegDigestMismatch before any execution (Pitfall 2) |
| T-04-07 | Spoofing | PvPRound consent | mitigate | ECDSA.recover per union member over hashPvPRound digest; BadPvPSignature(index); OZ ECDSA rejects malleable sigs |
| T-04-08 | Tampering | union-set manipulation | mitigate | strict-ascending enforcement on both inputs and the merge; exact one-signature-per-member count check |
| T-04-09 | Tampering | atomicity leak | mitigate | plain external calls only; comment-filtered grep gate proves no try/catch; both-or-neither revert tests land in plan 04-04 |
| T-04-10 | Elevation | router authority | mitigate | stateless, unowned, unpausable, no funds — nothing to elevate to; withdraw path on hubs untouched |
| T-04-11 | DoS | replay via leg nonces | accept | structural: hub roundNonce advance kills any signed bundle (RESEARCH Q2); replay test in plan 04-04; no router state added |
