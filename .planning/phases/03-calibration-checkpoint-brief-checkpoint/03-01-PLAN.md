<!-- Contracts this plan CREATES. Plans 03-02 and 03-03 implement against these exact exports — treat them as frozen once written. -->

From demo/thresholdModel.ts (to be created, Task 1):

- interface ThresholdParams: n, density, reciprocity, seed (all number), rounds (number, simulated rounds per history), uptime (number | number[] — constant p or per-round schedule for stress ramps), maxIousPerEdge? (number, passed through to generateFlows).
- interface ThresholdRoundRecord: kind ("settled-1pass" | "settled-2pass" | "aborted" | "empty"), excluded (string[], lowercase addresses excluded in this round, [] for 1-pass), settledVolume (bigint), grossVolume (bigint, over the consumed set only, straight from NetResult), consumedCount (number), deltas (Map<string, bigint>, lowercase address -> signed delta; empty Map for aborted/empty rounds), outflows (Map<string, bigint>, lowercase debtor -> gross outflow summed over this round's CONSUMED set; empty Map for aborted/empty rounds — feeds the worst-participant-saving metric in 03-02 and the margin debit series in 03-03).
- interface ThresholdHistory: records (ThresholdRoundRecord[]), excludedLatencies (number[], settlement latency in rounds for every IOU that was candidate-eligible at least one round before it settled), generatedCount (number, total IOUs generated), unsettledCount (number, IOUs still open at horizon end).
- function availabilityUniforms(seed: number, rounds: number, n: number): Float64Array — length rounds*n*2, generated from rng(seed ^ 0x5eed) in fixed round-major order: for r in 0..rounds-1, for member i in 0..n-1, emit uniform for pass 1 then pass 2. Member i is online in pass k of round r iff uniforms[r*n*2 + i*2 + (k-1)] < p_r (strict less-than). This is the SHARED draw stream plan 03-02's cross-validation harness replays against the real attemptRound.
- function deriveRoundSeed(seed: number, round: number): number — fixed formula ((seed * 31 + round * 2654435761) >>> 0), used to seed round r's fresh flow batch. Also shared with 03-02.
- function roundFlowBatch(seed: number, round: number, params: Pick<ThresholdParams, "n" | "density" | "reciprocity" | "maxIousPerEdge">): SignedIou[] — calls generateFlows({ ...params, seed: deriveRoundSeed(seed, round) }) and then REWRITES every IOU id to a round-unique 32-byte hex (fold the round index into the high 8 nibbles, keep generateFlows' per-batch counter in the low nibbles). REQUIRED: generateFlows resets its id counter on every call and derives ids from the counter alone (demo/flowModel.ts:49-67), so raw batches from different rounds share identical ids — net() rule 1 would dedup them and rule 3 would drop them against settledIds once an earlier round settles, silently discarding fresh paper and corrupting compression, latency, generatedCount/unsettledCount, and the margin debit series. Shared verbatim with 03-02's cross-validation harness (which remaps addresses only, never ids).
- function simulateThresholdHistory(params: ThresholdParams): ThresholdHistory — the model itself.
</interfaces>
